# Contributing

ABR welcomes thoughtful corrections and public-interest contributions to its documentation, education, transparency, and technical infrastructure.

## Appropriate Contributions

- Correcting spelling, formatting, broken links, or accessibility problems
- Improving public explanations without changing approved policy
- Suggesting educational resources
- Improving proof-of-reserve display code or documentation
- Identifying inconsistencies between public ABR materials

## Governance Changes

A GitHub pull request cannot, by itself, change the Reserve Policy, authorize a Bitcoin transaction, appoint a keyholder, approve a community release, or amend the governing documents of ABR Wealth Fund DAO LLC or ABR Foundation.

Proposed policy changes should clearly identify:

1. The provision affected
2. The proposed language
3. The reason for the change
4. Risks and tradeoffs
5. Whether formal governance approval would be required

## Security

Do not report security vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

Never include private keys, seed phrases, recovery material, credentials, personal information, or sensitive custody details in a contribution.

## Current Reserve Goal

The 21 BTC figure is ABR's long-term goal, not its current balance. Contributions must not describe the goal as current holdings.
