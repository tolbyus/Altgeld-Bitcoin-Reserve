# Security Policy

The Altgeld Bitcoin Reserve treats operational security, custody security, and public transparency as separate but connected responsibilities.

## Never Publish

Do not submit or publish any of the following in an issue, pull request, discussion, screenshot, or repository file:

- Seed phrases, private keys, PINs, passwords, or recovery words
- Hardware-wallet backup material
- Unredacted recovery instructions
- Server credentials, API secrets, access tokens, or private configuration files
- Personal addresses, identification documents, signatures, or private contact information
- Information that would expose the physical location of custody devices or backup material
- Unsigned or partially signed transactions unless disclosure is specifically approved as part of a controlled verification process

No legitimate ABR representative will ask anyone to post a seed phrase or private key.

## Public Reserve Information

ABR's public transparency record may include Reserve balances, approved public addresses, acquisitions, approved releases, transaction identifiers, current value, and community reporting. Publication must follow the Reserve Policy and must not expose private key material or unnecessary operational details.

The 21 BTC figure is a long-term goal, not the current Reserve balance.

## Reporting a Security Concern

Do not open a public GitHub issue for a suspected custody, website, wallet, or infrastructure vulnerability.

Report concerns privately to **altgeldreserve@gmail.com** with:

- A short description of the concern
- The affected page, system, or repository path
- Steps to reproduce, when safe
- Potential impact
- Your preferred contact information

Do not access, move, test, or attempt to control Reserve funds. Do not expose sensitive information to prove a vulnerability.

## Scope

This policy covers public ABR repository content and responsible reporting. It is not a complete custody manual, incident-response plan, or security audit.
